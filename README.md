Bank Account Management System (OOP)

A Python-based banking system demonstrating core Object-Oriented Programming principles: 'Encapsulation', 'Inheritance', and 'Data Validation'.

Features
- Private Attributes: Uses `__` private variables to prevent direct external access.
- Properties: Implements `@property` decorators for read-only account numbers and validated balance updates.
- Subclassing: Includes a `SavingsAccount` class that inherits from the base account.
- Transaction History: Basic logging for all deposits and withdrawals.

 How to Run
1. Ensure you have Python 3.x installed.
2. Run the script: `python bank_account.py`
